# Карта себя

Мягкое самоинтервью (3 захода) для понимания направления в работе и подбора курсов.

**Ссылка для прохождения:** https://dantrusov10.github.io/karta-sebya/

Ответы сохраняются в облако (GitHub Gist + файл `answers/state.json`) — можно продолжить с любого телефона по той же ссылке.

Ящик с копиями: https://ntfy.sh/karta-sebya-d10-7e4b9c2a1f

## Запуск локально

```bash
npm install
npm run dev
```

Открой ссылку из терминала (обычно `http://localhost:5173`). Для телефона в той же Wi‑Fi:

```bash
npm run dev -- --host
```

## Как пользоваться

1. Она проходит опрос в 2–3 захода — после **каждого** ответа прогресс пишется в браузер (localStorage).
2. Можно закрыть вкладку на любом вопросе и позже открыть ту же ссылку **в том же браузере на том же устройстве** → «Продолжить» с того же места. Срок не ограничен.
3. В конце скачивается `.txt` + открывается MAX с кратким текстом (нужно приложить файл в чат).
4. Ты забираешь файл из MAX / Загрузок и приносишь сюда в чат.

Важно: другой телефон, другой браузер или режим инкогнито = пустой прогресс. Сменился IP в ссылке `http://192.168…` — это уже другой «сайт», прогресс там не увидит.

## Доставка тебе «сама»

По умолчанию: скачивание `.txt` + диплинк MAX (`https://max.ru/:share?text=…`).

Если хочешь авто-отправку через webhook (Make/n8n) — пропиши URL в `src/config.ts`:

```ts
webhookUrl: 'https://…',
mailto: 'you@email.com', // опционально
```
